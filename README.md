# Pivot & Anchor: org defaults

- `ISSUE_TEMPLATE/`: default issue forms (Gate, Question, Defect, Feature, Change request) for every org repo that doesn't define its own. Each form adds the issue to the **Agentic Studio** project (org project #3).
- `studio/labels.json`: the studio label set. Apply it to a repo with `studio/sync-labels.sh <repo>`.

How the studio runs is described in the Agentic Studio project README.
